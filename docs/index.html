数据集把「能否公开」「全量包能否分发」「是否经过专家验证」当作三个独立的决定，并把当前状态如实写进每一份文档。本站展示的是其中可以公开的部分。

Architecture

四层架构：每一层都标明它是怎么来的

来源层与文本层由书目记录与确定性算法得到；派生层是机器检出、尚未审核的结果；解释层由大语言模型生成，并全部带有未审核标记。默认查询只返回确定性的结构，以及已声明机器来源的层。

Read this first

分析之前请先读这五条

  1. 两个「时代」字段不可互换。

    Person.person_historical_era 是人物自身所处的时代，Version.witness_era 是版本的时代。在两者皆已知的注疏行中，有 68.9% 二者不一致；跨时代分析请使用 Commentary.commentator_historical_era。

  2. 提及统计量的是文献全文，而不是《老子》经文。

    概念匹配在整篇文献文本上运行，经文、注文与编者按互相交错、并无格式区分；全量语料中至多 8.4% 的匹配文本是《老子》经文本身。请按 text_composition 过滤，并把这一层称为「文献文本的词汇提及」。

  3. 概念计数必须按 match_specificity 过滤。

    111 个概念名中有 33 个是单字（一、大、用……），同时也是普通词；81.4% 的原始提及来自单字匹配。按原始计数排名的前十与按高特异性计数排名的前十没有交集（Spearman −0.655）。

  4. 引用注疏须以 citable_as_quote 为门。

    2,386 条注疏中 1,282 条是连续的原文（verbatim_contiguous）；其余是模型拼接的摘录或未能定位的转述，不可当作注家原话引用。

  5. 异文皆为候选。

    每一行 variant_status = candidate_auto_detected；variant_detection_score 是启发式分数，不是概率；18,334 个事件无一经过校勘确认。

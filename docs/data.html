    Rights & licence

    权利与许可

    两层权利分开处理：作者自有的结构注释、派生层与代码，以 CC BY 4.0（注释）与 MIT（代码）发布；底本转录来自第三方平台，其数字化与转录层的权利尚未确定，因此从公开版中撤除。

    不主张的事。 CC BY 4.0 不覆盖底本转录；早先元数据中任何数据集级的「CC BY 4.0」标签，都只适用于作者自身的注释与代码贡献。
    • 结构注释与派生层（模式、概念本体、对齐、异文检测、提及层、注疏来源分类、图谱投影）：CC BY 4.0。
    • 代码（src/、qa/）：MIT（见 LICENSE_CODE）。
    • 底本转录：原著因年代久远属公有领域（175 种），但数字化替身与转录/OCR 劳动的权利按来源逐一待定；data/source_rights.csv 逐行记录。
    • 本网站：只呈现公开结构版中的内容；唯一的文本来自作者自有的现代整理本。
    Reproducibility

    「可复现」的三种含义

    路径公开结构版说明
    从发布表格重建图谱可以src/build_graph.py，确定性；build_report.json 记录每张表的行数与输入 SHA-256。
    从发布表格复算全部派生统计量与图可以QA 套件在每次发布时执行并比对。
    重新运行 QA 套件与验证评分器可以qa/validate_public_profile.py、src/score_validation.py。
    从原始输入重新生成表格不能legacy/ 不随公开版分发；需向作者索取全量内部包。
    依赖被撤除字符流的任何分析或判定不能设计使然：忠实度、哲学用法、异文真伪与对齐判定须在全量内部包中进行。

    work_type、node_type 与 35 条 LLM 语义关系由 MiniMax-M3 在修订时产生并作为数据随包发布；重新生成需要 API 访问，且不会得到完全相同的标签。
